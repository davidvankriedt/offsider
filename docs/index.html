How It Works

01

Panel Localization

A fine-tuned YOLO model tightly frames physical sign plates, isolating relevant regulatory graphics from background visual clutter.

02

OCR Parsing

Crops pass directly to an optical character recognition engine that extracts hours, time limits, and vehicle exemptions.

03

Rule Evaluation

Evaluates parsed regulations against the current timestamp and vehicle type to output immediate clearance guidance.
